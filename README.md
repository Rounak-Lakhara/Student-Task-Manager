# Student Task Manager

A simple student-focused task manager built with HTML, CSS, and vanilla JavaScript.

## Features
- Add tasks with title, priority, and optional due date
- Mark tasks completed or pending
- Filter all, pending, and completed tasks
- Delete tasks
- Persistent storage with browser localStorage
- Responsive layout for mobile and desktop

## Run locally
Open `index.html` in your browser. For a better development workflow, use VS Code Live Server.

## Files
- `index.html` – structure
- `style.css` – responsive styles
- `script.js` – task logic and local storage
